Autonomous AI Coding Agent (Python, Google Gemini API)

Engineered a functional AI agent capable of autonomously debugging and modifying codebases using Google’s Gemini Flash API.

Implemented an agentic loop architecture, moving beyond one-shot inference to a recursive system that iterates until a problem is solved.

Developed a robust Tool Calling (Function Calling) system, granting the LLM interfaces to read file metadata, modify source code, and execute Python scripts.

Designed complex System Prompts to enforce security constraints and guide the model’s decision-making process during file manipulation.

Integrated conversation history management to maintain context across multiple turns of the debugging lifecycle.
